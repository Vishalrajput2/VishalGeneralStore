# Vishal General Store Website

Official bilingual website for **Vishal General Store / विशाल जनरल स्टोर**.

## Included in this first version

- Premium mobile-first homepage
- Simple Hindi and English branding
- Product category section
- Mother Dairy ice-cream section
- Family Shopping List
- Select, type and voice input
- 4-digit list code and QR code
- Phone and Google Maps actions
- LocalStorage-based prototype (no online ordering/payment)

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Import this repository into Vercel and deploy with the default Next.js settings.

## Important

The current shopping-list system is a browser prototype. For lists to open on every counter worker's device, the next phase should connect it to Supabase.
